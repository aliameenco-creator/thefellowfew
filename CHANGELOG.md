# Changelog

## 0.1.0

First release of The Fallow Few theme, built from the archived original site (Wix Studio, one page).

- One-page layout in the original order: hero still with the title logo, TRAILER (YouTube, click-to-play), cast cards (arched photos, names, roles, IMDb links), THE STORY (DECEMBER 1916), GALLERY (ten stills with lightbox), partner logos (ORWO Studios, Black Hangar Studios, Glasshouse Pictures) and the original footer credit.
- Original menu labels: CAST, THE STORY, GALLERY (anchors on the home page).
- Footer year is printed at runtime (never copied from the old site).
- Subtle motion (title fade-in, scroll reveals, hover zoom), reduced-motion safe; content visible without JavaScript.
- Two-column cast and gallery on phones; no horizontal overflow at 390/360/320.
- Original title "HOME | The Fallow Few", canonical, Open Graph and Twitter tags; theme-served home URL added to the WordPress sitemap.
- One-click setup (permalinks, site title) and Media Library import of all 20 images with descriptive file names and alt text.
- GitHub release updater (Appearance > The Fallow Few Updates).
- The original site has no contact form, so none is included.
