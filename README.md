# The Fallow Few: WordPress theme

Custom one-page theme for the film *The Fallow Few*, rebuilt from the archived original site. Presentation changes only; all copy, names, roles, links and images come from the original.

Install: Appearance > Themes > Add New > Upload `the-fallow-few.zip`, activate, then click **Complete The Fallow Few setup** in the admin notice (permalinks, site title, Media Library images).

Updates: publish a numbered GitHub release (`vX.Y.Z`) with a `the-fallow-few.zip` asset; the theme's updater offers it under Appearance > The Fallow Few Updates.

Layouts in `parts/` are generated from the archive by the website migration tool (`tools/fallow_few_theme_content.py`); do not edit them by hand in this repository.
